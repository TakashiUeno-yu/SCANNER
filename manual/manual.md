# SCANNER 使用手順書

2026年10月21日 · 上野 孝

## はじめに

SCANNER は、広告なしで使える自分用のバーコード／QR リーダーです。iPhone の Safari で開いてホーム画面に追加すると、アプリのように使えます。

**できること**

- JAN・GS1 データバー（限定型・二層型・標準型・拡張型）・GS1-128・QR・Data Matrix などの読み取り
- 医療用医薬品の GS1 コードから、販売名・規格・包装・メーカーを表示（医薬品マスターの取り込みが必要）
- バーコード上の小さい2次元部分（合成シンボル）から、有効期限・ロットを読み取り
- PMDA の電子添文・関連文書を開く
- 写真上でバーコードのサイズを計測

**使う版**

| 版 | アドレス | 連続読み取り | 用途 |
| --- | --- | --- | --- |
| GitHub 版（ふだん使う版） | https://takashiueno-yu.github.io/SCANNER/ | 使える | iPhone のホーム画面に追加して使う |
| Artifact 版 | Claude アプリの中で開く | 使えない（撮影・写真のみ） | 動作確認用 |

この手順書は GitHub 版の使い方です。2つの版は別々に動いており、履歴と医薬品マスターも別々に保存されます。

## 1. ホーム画面にアイコンを追加する

最初に1回だけ行います。必ず **Safari** で開いてください（Chrome などでは「ホーム画面に追加」の動きが異なります）。

1. iPhone の **Safari** で https://takashiueno-yu.github.io/SCANNER/ を開く（SCANNER は大文字で入力。小文字だと開けません）
2. 画面下のアドレスバー左端の **「≡」**（横線3本のアイコン）を押す
3. 出てきたメニューの **「共有」** を押す
    - 上に「SCANNER」の緑のアイコンと「takashiueno-yu.github.io」が出る
4. 一覧の **「ホーム画面に追加」** を押す（「ページを検索」の下）
5. 名前が「SCANNER」になっていることを確認する
    - 「Web アプリとして開く」のスイッチが出たら **オン** のままにする
6. 右上の **「追加」** を押す
7. ホーム画面に緑色の「SCANNER」アイコンが出る。以降はこのアイコンから起動する

[[FIG n_safari.png|手順2：アドレスバー左端の「≡」を押す;;n_menu.png|手順3：メニューの「共有」を押す;;n_share.png|手順4：「ホーム画面に追加」を押す]]

[[FIG n_home.png|ホーム画面のアイコンから開いた画面（アドレスバーが無い）]]

アイコンから開くと、Safari のアドレスバーが無い全画面で動きます。初めて「連続読み取り」を押したときにカメラの利用を聞かれるので、**「許可」** を選んでください。

**カメラの許可を毎回聞かれないようにする（おすすめ）**

ホーム画面のアイコンから起動すると、「連続読み取り」を押すたびに「“takashiueno-yu.github.io” がカメラへのアクセスを求めています」と聞かれることがあります。これは iPhone 側の仕組みで、アプリの中からは記録できません。次の設定で出なくなります。

1. iPhone の **設定** を開く
2. **アプリ** → **Safari** を開く（iOS の版によっては 設定 → Safari）
3. 下の「Web サイトの設定」にある **カメラ** を押す
4. 「すべてのウェブサイトでカメラへのアクセス」を **「許可」** にする
5. SCANNER を完全に閉じて（アプリ切り替え画面で上にスワイプ）開き直す

[[FIG c_camera.png|設定 → アプリ → Safari → カメラ を「許可」にする]]

この設定は Safari で開くすべての Web サイトに効きます。ほかのサイトでも聞かれずにカメラが使えるようになるので、気になる場合は「確認」に戻してください（毎回聞かれる状態に戻ります）。

## 2. 医薬品マスターを取り込む（初回と月1回）

薬品名を表示するには、MEDIS の「医薬品コード」全件ファイルを iPhone に取り込みます。取り込んだデータは iPhone の中だけに保存され、どこにも送信されません。

1. SCANNER を一番下までスクロールし、「医薬品マスター（薬品名の表示用）」を開く
2. **「① 医薬品コード（全件）をダウンロード」** を押す
    - 前月末日の版（例：`A_20260930_2.zip`）のアドレスはアプリが自動で作ります
    - 「ダウンロードしますか？」と聞かれたら **「ダウンロード」** を押す（約 1.6MB）
3. SCANNER に戻り、**「② マスターを読み込む」** を押す
4. 「ファイルを選択」→ **「ダウンロード」フォルダ** → `A_年月日_2.zip` を選ぶ（zip のままでよい）
5. 数秒待ち、「医薬品コード：2026-09-30版　56,942品目…」のように出れば完了

[[FIG n_master1.png|読み込む前のマスター欄。①でダウンロード、②で読み込み;;n_master2.png|読み込んだ後。上に版と件数が出る]]

**更新**：月が替わると①の下に「新しい版があります」と出ます。同じ手順（①→②）で読み込み直してください。月初めで前月分がまだ公開されていないときは、①を押すとエラーページになります。そのときは数日待つか、マスター欄の「医薬品コード 全件CSV」のリンクから公開中の版を選びます。

**HOT コードも表示したいとき（任意）**：「HOT コードも表示したいとき」を開き、MEDIS の HOT コードマスター（`h年月日_h.zip`）を同じく②で読み込むと、結果に HOT13 コードも出ます。

「削除」を押すと、取り込んだマスター（医薬品コード・HOT の両方）が消えます。

## 3. 読み取り方

ふだんは「連続読み取り」を使います。読めた瞬間にカメラが止まり、結果画面に切り替わります。

[[FIG n_live.png|連続読み取り中。バーコードを枠に入れて手を止める;;n_result.png|読めると結果画面に切り替わる。下の「続けて読む」で次へ;;a_shot_result.png|「撮影して読み取る」の結果。下は「もう一度撮影」]]

| 方法 | 使いどころ | 操作 |
| --- | --- | --- |
| 連続読み取り | ふだん使い。次々に読む | 「連続読み取り」を押し、バーコードを枠に入れて手を止める |
| 撮影して読み取る | 小さい・読みにくいコード、期限・ロットを確実に読みたいとき | 「撮影して読み取る」→ カメラで撮る→「写真を使用」 |
| 写真から選ぶ | 撮っておいた写真やスクリーンショット | 「写真から選ぶ」→ 写真を選ぶ |
| 手入力・貼り付け | バーコードが傷んで読めないとき | 結果欄の入力欄に番号を入力して「確認」 |

**結果画面のボタン**

- **続けて読む**：カメラに戻って次のコードを読む（連続読み取りから来たとき）
- **もう一度撮影**：カメラを開いて撮り直す（撮影・写真から来たとき）
- **閉じる**：最初の画面に戻る

**手入力のこつ**

- 標準カメラで印字を写し、文字認識（テキストを長押し→コピー）でコピーした番号を貼り付けると、自動で確定します。全角数字や空白が混じっていても構いません。
- 医薬品を表示中に「(17)…(10)…」だけを貼り付けると、表示中の商品コードと合体して期限・ロットが入ります。

連続読み取り中にホーム画面へ戻ったり iPhone をロックしたりすると、カメラは自動で止まります。戻ると自動で再開します。

## 4. 結果画面の見方

結果画面には、読んだコード、種類のラベル、医薬品なら「添文ナビ（PMDA）」の表が出ます。

[[FIG a_live_result.png|医療用医薬品の結果。販売名・規格・包装・期限・ロットなど;;a_shot_result2.png|下までスクロールすると有効期限・ロットと電子添文のボタン]]

**種類のラベル（判定ルール）**

| ラベル | 条件 | 表示されるもの |
| --- | --- | --- |
| 医療用医薬品 | 医薬品マスターに載っている、または GS1 コードの先頭3桁が 049・149・249・045・145・245 | 販売名などの表、添文ボタン |
| インストアコード | 先頭1桁を除いた番号が 2 で始まる（20〜29） | お店独自の番号（古書店の値札など）。医薬品ではない |
| GS1 商品コード | 上のどれでもない 14 桁の GS1 コード | 商品コードのみ |
| JAN・ISBN など | 13 桁など | チェックデジット、国コード、検索リンク |

**包装単位**（GS1 コードの先頭1桁）

| 先頭 | 包装単位 | 例 | 普通のバーコード |
| --- | --- | --- | --- |
| 0 | 調剤包装単位 | PTP シート、アンプル、輸液バッグ | DataBar 限定型（小さいものは二層型） |
| 1 | 販売包装単位 | 個箱 | DataBar 限定型＋合成シンボル（期限・ロット必須） |
| 2 | 元梱包装単位 | 段ボール | GS1-128（数量・期限・ロット） |

**添文ナビの表に出る主な項目**：販売名、規格、包装、剤形、製造販売、区分、薬価基準コード、商品コード（GTIN）、包装単位、有効期限、ロット。麻薬・生物由来製品・販売中止は該当するときだけ出ます。

- **電子添文を開く**：PMDA の添付文書ページが開きます（調剤包装単位のコードでも開けます）。
- **表示ルールとの違い**：包装単位とバーコードの種類が表示ルールと合わないときに出ます。読み違いの可能性もあるので、気になれば読み直してください。
- **マスターに見つかりません**：発売前後の新しい製品など。マスターを最新版にすると出ることがあります。

## 5. 期限・ロットをうまく読むコツ

有効期限 (17) とロット (10) は、箱などのバーコードの上にある小さい2次元部分（合成シンボル）に入っています。細かいので、次の点に気をつけると読みやすくなります。

- バーコードが画面幅の半分以上になるまで近づく
- 上の2次元部分まですべて枠に入れる
- ピントが合うまで手を止める（連続読み取りは、確定直後のコマで探します）
- 光の反射が入らない角度にする（フィルム包装やツヤのある箱は特に）
- 連続読み取りで読めないときは、**「撮影して読み取る」** で静止画を撮る（解像度が高いぶん読めやすい）
- それでも読めないときは、上に印字された「(17)…(10)…」を標準カメラの文字認識でコピーし、貼り付ける

調剤包装単位（先頭 0、PTP シートなど）は期限・ロットの表示が任意なので、合成シンボルが無いことがよくあります。

## 6. その他の機能

**履歴**

- 読んだコードは最大 300 件まで、iPhone の中に残ります（新しい順）
- 履歴を押すと、そのコードの結果画面をもう一度開けます
- 「削除」で1件ずつ、「すべて削除」で全件消せます

**サイズ計測**（バーコードの幅・高さを測る）

1. 金指しをバーコードと同じ面に密着させ、真上から「撮影して読み取る」で撮る
2. **「この写真でサイズを測る」** を押す
3. 黄の線の両端を金指しの目盛りに合わせ、その間の長さを 10／20／30／50／100mm のボタン（または入力欄）で指定する
4. 緑の線をバーの左端と右端に、青の線を通常のバーの上端と下端に合わせる
5. 細かい調整は、丸をタップして選んでから矢印ボタン（1 ピクセルずつ）で行う
6. 幅・高さ（mm）、JAN なら細バー幅・倍率（80〜200% 判定）が出る。「結果をコピー」でメモに貼れる

[[FIG a_measure_c.png|計測画面。黄＝金指しの目盛り、緑＝バーの幅、青＝バーの高さ。下に幅・高さ・倍率]]

目盛りはなるべく離れた2点を選ぶと誤差が小さくなります。斜めから撮ると誤差が出ます。

## 7. 困ったとき

| こんなとき | 対処 |
| --- | --- |
| 起動するたびにカメラの許可を聞かれる | 設定 → アプリ → Safari → カメラ を「許可」にする（1章参照） |
| 「連続読み取り」でカメラが起動しない | 設定 → アプリ → Safari → カメラ を「確認」か「許可」にする。アプリを完全に閉じて開き直す |
| 「連続読み取り」ボタンが無い | Artifact 版（Claude アプリ内）では使えません。GitHub 版を開く |
| 「見つかりませんでした」と出る | 近づいてピントを合わせて撮り直す。読めなければ番号を手入力・貼り付け |
| 販売名が出ない | 医薬品マスターを読み込んでいるか確認。古い場合は最新版を読み込む |
| ①を押すとエラーページ（404）になる | 前月分がまだ公開されていない。数日待つか、公開中の版をリンク先から選ぶ |
| 「読み込めませんでした」と出る | 「調剤包装単位・販売包装単位・元梱包装単位コードファイル（ZIP）」（`A_年月日_2.zip`）を選んでいるか確認 |
| アプリを更新したのに前のまま | アプリ切り替え画面で SCANNER を上にスワイプして完全に閉じ、開き直す |
| 本や日用品が医薬品と出る | 先頭が 045／049 などの 14 桁コードは医薬品と判定します。マスターに載っていなければ「マスターに見つかりません」と出るので、それで区別する |
| 履歴やマスターが消えた | Safari の履歴・データを消去すると消えます。マスターは①→②で読み込み直す |

## 8. 注意事項

- **データの保存場所**：読み取り、履歴、医薬品マスターは、すべて iPhone の中だけで扱います。外部に送信するのは、添文・検索のボタンを押したときのページ表示だけです。
- **医薬品マスターの利用条件**：MEDIS（一般財団法人 医療情報システム開発センター）の無償公開データを、自分の端末に取り込んで使っています。データを GitHub などに置いて他の人に配らないでください（再配布を認める記載が無いため）。業務で使う場合は MEDIS の利用条件を確認してください。
- **電子添文**：著作権は各製造販売業者にあります。
- **判定の限界**：医薬品の判定と表示は確認の補助です。調剤や照合などの業務判断には使わないでください。
- **アプリの更新**：GitHub（TakashiUeno-yu/SCANNER）の `index.html` を差し替えると、1〜2分で公開ページに反映されます。iPhone 側はアプリを完全に閉じて開き直すと新しい版になります。元のファイルと履歴は PC の `C:\claude\2026-10_iphone-apps\` にあります（`HANDOFF.md` に経緯）。
